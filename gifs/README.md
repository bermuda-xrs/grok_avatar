One folder per state. Put `.gif`, `.webp` or `.png` files in it; with several, one is picked at random each time the state starts. An empty folder shows a plain dot.

| Folder | Shown when |
|---|---|
| `standby` | idle |
| `hover` | the mouse is over the avatar |
| `drag` | the avatar is held or dragged |
| `processing` | a bot is working |
| `done` | a bot just finished (5 s) |

Priority: drag > processing > done > hover > standby. After adding files, right-click the avatar → **Reload GIFs**.
